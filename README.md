# 3QInnova

Official website for [3QInnova LLC](https://3qinnova.com), a technology consulting, software engineering, cloud, AI, telecommunications, and interactive-product company.

## Website

This site is intentionally lightweight and dependency-free. It uses semantic HTML, responsive CSS, and a small amount of JavaScript, making it fast and inexpensive to host on GitHub Pages.

## Local preview

Open `index.html` directly in a browser or serve the directory with any static web server.
